# لو | What iF ⏳🎓

محاكي تخرج ومعدل لطلاب وطالبات الإحصاء في جامعة الملك سعود (موقع غير رسمي).

**جرّبه:** https://farooha1.github.io/whatif

## وش يسوي؟
- خريطة تفاعلية لخطة بكالوريوس الإحصاء (136 ساعة) مع فرعي الذكاء الاصطناعي (156 ساعة)، متطلبات كل مادة ووش تفتح
- حاسبة المعدل على سلم 5 مع احتساب كل المحاولات المعادة
- سيناريوهات «لو»: لو أجلت مادة؟ لو رسبت؟ لو سجلت ساعات أكثر؟ مع جدول زمني ترم بترم
- أدوات المعدل: المعدل المستهدف، ووش أحتاج في النهائي
- توقعات «لو»: محاكاة مونت كارلو (1000 مستقبل) بنموذج إحصائي فيه Bayesian shrinkage وتأثير عشوائي مشترك
- تنبيهات ذكية، ومساعد اختيار المواد الاختيارية
- تقييمات المواد (Supabase) بدون تسجيل دخول
- عربي / English، فاتح / داكن، طالب / طالبة
